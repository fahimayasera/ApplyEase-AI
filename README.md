# ApplyEase AI

**Bilingual AI-Powered Scholarship Application Readiness Auditor**

## About the Project

Applying for scholarships can be confusing, especially when students have to understand eligibility rules, collect documents, and keep track of application requirements.

**ApplyEase AI** is a platform designed to make this process easier. It brings important application preparation tasks together in one place, helping students organize their information, upload documents, and check their application readiness.

## Why We Built It

Many students find scholarship applications difficult because they are unsure about the required documents, eligibility conditions, and other instructions.

We wanted to create a simple platform that helps students feel more organized and confident while preparing their applications.

## What It Offers

- **My Student Profile:** Add and manage personal, educational, and institution details.
- **Document Upload:** Upload and manage multiple supporting documents.
- **PDF Text Extraction:** Extract readable text from uploaded PDF files.
- **Review & Complete:** Check profile information and review document readiness.
- **Application Guidance:** Understand important topics such as eligibility, income requirements, supporting documents, deadlines, and verification.
- **Simple Dashboard:** Access all the main features from one place.

## Technologies Used

- Python
- Streamlit
- PyPDF
- HTML
- CSS

## Getting Started

Follow these steps to run ApplyEase AI on your computer.

**1. Clone the repository**

```bash
git clone https://github.com/fahimayasera/ApplyEase-AI.git
```

**2. Open the project folder**

```bash
cd ApplyEase-AI
```

**3. Install the required packages**

```bash
pip install -r requirements.txt
```

**4. Start the application**

```bash
streamlit run app.py
```
